# shan_word_guess

A Flutter application for Shan language word guessing game. This app helps users learn and practice Shan language vocabulary through an interactive game interface.

## Features

- Interactive word guessing game
- Custom Shan language font support
- Responsive design for multiple platforms
- Engaging user interface with Flutter Material Design

## Built With

- [Flutter](https://flutter.dev) - UI toolkit
- [Dart](https://dart.dev) - Programming language
- [Material Design](https://m3.material.io) - UI components
- Custom Shan language font (AJ13)

## Project Structure

```
lib/
├── screens/          # UI screens (Home screen implemented)
├── tools/            # Utility functions and helpers
└── main.dart         # Entry point of the application
```
